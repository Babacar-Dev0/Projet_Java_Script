# Quiz Interactif

**Auteur :** Babacar Ndiaye
**Licence 1 — Informatique**
**Cours :** Technologie Web — Mini-projet JavaScript & DOM

## Description

Application web interactive en JavaScript pur (sans framework ni librairie externe), consistant en un quiz à choix multiples.

L'utilisateur répond à une série de questions en cliquant sur une réponse. Après chaque réponse, l'application indique immédiatement si elle est correcte ou non, puis permet de passer à la question suivante. À la fin du quiz, le score final s'affiche, avec la possibilité de recommencer.

## Comment utiliser l'application

1. Ouvrir le fichier `index.html` dans un navigateur web.
2. Cliquer sur une réponse pour chaque question.
3. Cliquer sur "Question suivante" pour continuer.
4. À la fin, consulter le score et cliquer sur "Recommencer" pour rejouer.

## Structure du projet

- `index.html` : structure de la page.
- `style.css` : mise en forme et styles visuels.
- `script.js` : logique de l'application (données, fonctions, gestion des événements et du DOM).

## Notions mises en œuvre

- Gestion d'événements utilisateur (clics)
- Manipulation dynamique du DOM (création, modification, suppression d'éléments)
- Structures conditionnelles (vérification de la réponse)
- Boucles (génération des boutons de réponse à partir des données)
- Organisation du code en fonctions claires
- Jeu de données statiques (tableau d'objets JavaScript)
